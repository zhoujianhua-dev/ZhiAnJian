常用接入：DeepSeek（api.deepseek.com/v1）、阶跃星辰（api.stepfun.com/v1）、 通义千问（dashscope.aliyuncs.com/compatible-mode/v1）、 OpenAI（api.openai.com/v1）、本地 Ollama（localhost:11434/v1）。
模型不用记名字：填好 Base URL 与 API Key 后点「⬇ 从上游获取模型」，在列表里勾选一个即可 （打开本页时会自动拉取一次；上游返回不了列表时，可点「手动填写」）。
连不上时：①确认当前网络已完成网页认证，或直接换手机热点；②开启本机代理软件后，在上方填写代理地址再“测试连接”。

统一 AI 配置 智安鉴与 Shelling 共用这一份模型配置

读取中…
智安鉴的 Base URL / 模型 / API Key 是全系统唯一配置源。保存时自动同步给 Shelling， 使 Shelling 扫描同样具备 AI 分析（漏洞摘要、AI 分析、整改建议、误报评分）。
注意：上方「网络代理」只对智安鉴生效，Shelling 侧不支持代理。
